# Формат: "$ команда", вывод (stdout+stderr), [exit код]. Пустая строка между "$ команда" и "[exit N]" это вывод "\n" (одна пустая строка).
# Блоки с пометкой «ЗАМЕТКА» фиксируют поведение git, которое тренажёр не воспроизводит (отказ области или хвост).
