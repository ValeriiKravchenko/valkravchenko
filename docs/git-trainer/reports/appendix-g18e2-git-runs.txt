# Прогоны git 2.53.0, 18.10.2026 (поток g18e2), LC_ALL=C, GIT_PAGER=cat, GIT_CONFIG_NOSYSTEM=1, HOME и XDG_CONFIG_HOME внутри каталога из mktemp -d,
#   git запускается как `git -c log.decorate=short -c init.defaultBranch=master`, под stdbuf -oL -eL: порядок строк stdout и stderr такой, как на терминале.
# Автор и коммиттер: Валера <valera@example.com>. Каждая команда сдвигает часы на минуту (GIT_AUTHOR_DATE/GIT_COMMITTER_DATE),
#   поэтому хэши воспроизводимы только внутри блока и от хэшей других файлов отличаются. Каждый блок начинается с исходной истории раздела 8, как в П8.1
#   (файлы кончаются переводом строки: app.js, README.md, about.html), HEAD на master, рабочий каталог чист; после блока каталог удалён.
# Служебные шаги: `edit <файл>` дописывает ` + правка` перед концом строки файла (так ✎ меняет файл в тренажёре), `mkfile <файл>` создаёт файл
#   с одной строкой «новый файл», `rm <файл>` удаляет файл. Это не команды git; вывода у них нет.
# Формат: "$ команда", вывод (stdout+stderr), [exit код]. Пустая строка в конце вывода команды — это перевод строки в конце вывода git.
# Вывод `git commit` содержит после первой строки диффстат и ` create mode …`; тренажёр их не печатает (target.md, часть X, «Автор и дата в разделе 8»).
# Блоки П8.41–П8.56 дополняют П8.3 и П8.14 (section8-git-runs.txt): ссылки на тайники, ошибки ссылок, сообщения, что попадает в тайник, apply и pop на непустом дереве,
#   `git checkout -- <файл>` и `git checkout <файл>`.
