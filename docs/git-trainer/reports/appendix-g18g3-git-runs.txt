# Прогоны git 2.53.0, 19.10.2026 (поток g18g3), LC_ALL=C, GIT_PAGER=cat, GIT_CONFIG_NOSYSTEM=1, HOME и XDG_CONFIG_HOME внутри каталога из mktemp -d,
#   git запускается как `git -c log.decorate=short -c init.defaultBranch=master`, под stdbuf -oL -eL: порядок строк stdout и stderr такой, как на терминале.
# Автор и коммиттер: Валера <valera@example.com>. Каждая команда сдвигает часы на минуту (GIT_AUTHOR_DATE/GIT_COMMITTER_DATE), поэтому хэши воспроизводимы
#   внутри файла и зависят от порядка команд. Каждый блок начинается с исходной истории раздела 8, как в П8.1 (файлы кончаются переводом строки), HEAD на master,
#   рабочий каталог чист; после прогона каталог удалён. Каталог прогона в выводе заменён на /work.
# Служебные шаги: `edit <файл>` дописывает ` + правка` перед концом строки файла, `mkfile <файл>` создаёт файл с одной строкой «новый файл», `rm <файл>` удаляет файл.
#   Это не команды git; вывода у них нет. Команды с `-q` — подготовка, их вывод образцом не служит. Слово `{short:…}` в записи команды заменено настоящими 7 знаками id.
# <CR> — символ возврата каретки (\r) перед следующей строкой хода rebase (`Rebasing (k/n)`), как в section8-git-runs.txt.
# Блоки П8.82–П8.88 закрывают формы rebase, которых нет в section8-git-runs.txt (П8.6–П8.12, П8.16–П8.18): правки одновременно в индексе и рабочем каталоге,
#   порядок проверок (`invalid upstream` раньше правок, правки раньше `up to date`), удалённый файл, неотслеживаемый файл, запись `rebase (start)` для тега,
#   id7, `<ссылка>~n` и `refs/heads/…`, несколько пропущенных коммитов, все коммиты пропущены, rebase после reset.
# Формат: "$ команда", вывод (stdout+stderr), [exit код]. Пустая строка в конце вывода команды — это перевод строки в конце вывода git.

===== П8.82. REBASE: правки в рабочем каталоге и порядок проверок
$ git checkout -q feature
[exit 0]

$ edit app.js
[exit 0]

$ git rebase master
error: cannot rebase: You have unstaged changes.
error: Please commit or stash them.
[exit 1]

$ git add app.js
[exit 0]

$ git rebase master
error: cannot rebase: Your index contains uncommitted changes.
error: Please commit or stash them.
[exit 1]

$ edit about.html
[exit 0]

$ git rebase master
error: cannot rebase: You have unstaged changes.
error: additionally, your index contains uncommitted changes.
error: Please commit or stash them.
[exit 1]

$ git rebase nosuch
fatal: invalid upstream 'nosuch'
[exit 128]

$ git rebase feature
error: cannot rebase: You have unstaged changes.
error: additionally, your index contains uncommitted changes.
error: Please commit or stash them.
[exit 1]

$ git reset -q --hard
[exit 0]

$ rm about.html
[exit 0]

$ git rebase master
error: cannot rebase: You have unstaged changes.
error: Please commit or stash them.
[exit 1]

$ git checkout -q -- about.html
[exit 0]

$ mkfile notes.txt
[exit 0]

$ git rebase master
Rebasing (1/2)<CR>Rebasing (2/2)<CR>Successfully rebased and updated refs/heads/feature.
[exit 0]

$ git status --short
?? notes.txt
[exit 0]
